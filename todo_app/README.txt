오늘의 할 일 앱
================

실행 방법
1. 압축을 풉니다.
2. index.html 파일을 더블 클릭해 브라우저에서 엽니다.

구성
- index.html : 화면 구조
- style.css : 디자인 및 반응형 스타일
- script.js : 할 일 추가/수정/삭제/완료, 검색, 필터, 브라우저 저장
- images/ : SVG 이미지 3개

데이터는 현재 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저와 자동 동기화되지는 않습니다.
인터넷 연결이 없어도 기본 기능은 사용할 수 있습니다. (웹폰트는 인터넷 연결 시 적용)
